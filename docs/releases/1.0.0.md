# Phone Use 1.0.0

让 AI 看见并操作你的 Android 手机，由你在手机上批准访问。

## 下载与安装

- **手机用户：下载 `PhoneUse-1.0.0.apk`**，在 Android 11 或更新版本上安装。
- 开启无障碍服务，启动 Phone Use，在电脑端连接 App 显示的地址，核对配对码并在手机批准。
- AI 接入步骤见[中文指南](https://github.com/nidhoggfgg/PhoneUse/blob/v1.0.0/docs/integrations.zh-CN.md)。
- `phone-use-1.0.0.zip` 是离线 Skill；`phoneuse-mcp-1.0.0.zip` 是离线 MCP 接入包，按需下载。
- `SHA256SUMS.txt` 用于校验下载文件；源码和分发包采用 MIT 许可证。

## 本版功能

界面树与截图观察、点击与滑动、文字输入、应用切换、Web 控制台、MCP 与 Skill 接入、多设备管理、手机端配对授权及暂停/停止。

## 使用条件

手机和 AI 客户端需要网络互通；当前使用未加密的 HTTP，请在可信局域网使用。AI 客户端在手机外运行，屏幕内容会提供给连接的客户端，具体模型的数据处理取决于你选择的客户端及服务。部分系统需要为侧载应用允许“受限设置”；后台策略、受保护窗口及自定义控件可能影响操作。测试覆盖见[验证指南](https://github.com/nidhoggfgg/PhoneUse/blob/v1.0.0/docs/validation.zh-CN.md)。

## English

Download **PhoneUse-1.0.0.apk** for Android 11+. Enable accessibility, start the service, connect your AI client and approve pairing on the phone. See the [integration guide](https://github.com/nidhoggfgg/PhoneUse/blob/v1.0.0/docs/integrations.md).

This release provides screen observation, touch and text input, app navigation, a web console, MCP and Skill integrations, multiple-device management, and local pause/stop controls. The ZIPs are optional offline integrations. Checksums and the MIT license are included.

Use a trusted local network: transport is currently unencrypted HTTP. Screen data goes to the connected client; model-side data handling depends on your chosen client and provider. Restricted settings, vendor background policies and protected/custom UI can affect functionality. See the [validation guide](https://github.com/nidhoggfgg/PhoneUse/blob/v1.0.0/docs/validation.md) for coverage.
