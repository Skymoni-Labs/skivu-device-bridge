# Phone Use 1.1.0

本版新增 HTTPS 连接、公钥绑定和八位配对码核对，并将 Skill 拆分为独立仓库。

## 下载与升级

- 下载 `PhoneUse-1.1.0.apk`，在 Android 11 或更新版本上安装。
- **手机 App 和电脑端 Skill／MCP 客户端都需要更新，并重新配对一次。** 旧 HTTP 凭证不再用于 HTTPS 连接，不支持降级到 HTTP。
- 连接 App 显示的 HTTPS 地址，逐位核对手机与客户端显示的全部八位码，在手机批准后，再在客户端确认一致。
- Skill 安装命令：`npx skills add nidhoggfgg/phone-use-skills --skill phone-use`。
- `phone-use-1.1.0.zip` 和 `phoneuse-mcp-1.1.0.zip` 分别提供离线 Skill 与 MCP 接入包；`SHA256SUMS.txt` 提供文件校验值。

## 主要变化

- 手机服务使用 HTTPS（TLS 1.2/1.3），每次安装生成独立的 Android Keystore 密钥；原生客户端保存并验证公钥绑定。
- 首次配对增加双端八位码核对和客户端显式确认；公钥变化时拒绝连接，避免自动信任替换后的身份。
- 将静态界面标签归入可操作目标，改善 AI 对界面操作对象的理解。
- Skill 通过独立仓库分发，主仓库通过 Git 子模块维护同步副本。

手机与客户端仍需网络互通。浏览器直连需要独立建立证书信任；网页授权码不能替代原生客户端的八位码核对。详情见[接入指南](https://github.com/nidhoggfgg/PhoneUse/blob/v1.1.0/docs/integrations.zh-CN.md)和[传输安全说明](https://github.com/nidhoggfgg/PhoneUse/blob/v1.1.0/docs/transport-security.zh-CN.md)。

## English

This release adds HTTPS connections, pinned server public keys, and eight-digit pairing verification. It also distributes the Skill from a standalone repository.

Download **PhoneUse-1.1.0.apk** for Android 11+. **Update both the Android app and the Skill/MCP client, then pair again.** Old HTTP credentials are not reused, and HTTP fallback is not supported. Connect to the HTTPS address shown in the app, compare all eight digits on both devices, approve on the phone, and explicitly confirm the match in the client.

The phone uses TLS 1.2/1.3 with an installation-specific Android Keystore key. Native clients pin the public key and reject unexpected key changes. Static UI labels are now grouped under actionable targets. Install the standalone Skill with `npx skills add nidhoggfgg/phone-use-skills --skill phone-use`; versioned Skill and MCP ZIPs are available for offline installation, with checksums in `SHA256SUMS.txt`.

The phone must remain reachable from the client. Browser access requires independently established certificate trust; browser authorization codes do not replace native eight-digit verification. See the [integration guide](https://github.com/nidhoggfgg/PhoneUse/blob/v1.1.0/docs/integrations.md) and [transport security guide](https://github.com/nidhoggfgg/PhoneUse/blob/v1.1.0/docs/transport-security.md).
